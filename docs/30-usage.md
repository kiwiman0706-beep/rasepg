# 使い方(すべて Web から)

管理は 2 つの Web 画面だけで完結します。

| 画面 | URL | 役割 |
|---|---|---|
| **RASEPG Admin** | `http://<IP>:9000` | 保存先/NAS/エンコード/サービス/システム設定 |
| **EPGStation** | `http://<IP>:8888` | 番組表・予約・録画管理・視聴 |

## 初回セットアップ手順(Admin パネル)

1. `http://<IP>:9000` を開く(初回ログイン: `admin` / 初期パスワード)
   - 初期パスワードは Pi 上の `/etc/rasepg/config.json` に生成されています。
   - SSH できない場合でも、まずは Imager で設定したユーザで一度だけ確認が必要です。
     → セキュリティのため **[システム] タブで必ずパスワードを変更**してください。
2. **[保存先/NAS] タブ**
   - 「一時保存先」: 外付けSSDのデバイスを選び、パス(例 `/mnt/ssd/recorded`)を設定 → 保存
   - 「最終保存先(NAS)」: NAS の IP・共有名・ユーザー・パスワード・マウント先 → 「NAS を接続」
3. **[エンコード] タブ**
   - 既定は **Remux(再エンコ無し・原画質)** 推奨。持ち出し用に軽量化したいときだけ HW/SW を使用
   - HW/SW の画質数値のみここで調整 → 反映
4. **[サービス] タブ** → 「起動」(初回起動で自動起動済みなら不要)
   - ここで **チューナー backend(Mirakurun / mirakc)** も切替えられます(下記参照)
5. **[ダッシュボード]** → 「チャンネルスキャン実行」(数分)
6. EPGStation(`:8888`)を開き、番組表から予約 or キーワード自動予約ルールを作成
   - **通常のルール**: エンコードに `Remux-MP4` を指定 → 原画質MP4を一瞬で生成(Pi4無負荷)
   - **持ち出したい番組のルール**: `HW-H264-720p-2Mbps`(軽量) を指定
   - 「元TSを削除」を ON にすると、変換後は MP4 のみ NAS に残ります(Remux 時は原画質MP4)

## 放送中のライブ視聴(ブラウザ)

EPGStation の番組表から放送中の番組を選び「視聴」でブラウザ再生できます。

- **無変換(低遅延)**: EPGStation 内蔵の mpegts.js プレイヤーで再生。**Pi4 に最も優しい**(変換しない)。PC ブラウザ向けの本命。
- **720p (HW変換)**: スマホ等で互換性が要るときに Pi4 の HW エンコーダで変換して配信。

> 4ch すべてが録画中だとライブ視聴用のチューナーが空かないことがあります(チューナー数=同時ストリーム数の上限)。

## チューナー backend の切替(Mirakurun ⇄ mirakc)

[サービス]タブの「チューナー backend」で切替えられます。切替時は EPGStation の接続先(`mirakurunPath`)も自動で書き換わり再起動します。

- **Mirakurun(既定)**: 情報量が多く初期セットアップが安心。**まずはこちらで動作確認を推奨**。
- **mirakc(軽量)**: Rust 製で省メモリ・低負荷。安定後に切替えると Pi4 に余力が出ます。

**mirakc のチャンネル設定**: mirakc は API スキャンを持たないため、チャンネルは `stack/mirakc/config.yml` で管理します。かんたんな手順:

1. まず Mirakurun でチャンネルスキャン(ダッシュボードのボタン)を実行 → `stack/mirakurun/channels.yml` が生成
2. その `channel:` 値を `stack/mirakc/config.yml` の `channels:` に転記(物理ch番号は共通)
3. [サービス]タブで mirakc に切替え

## 変換方式の使い分け(Pi4 + PX-Q1UD の推奨運用)

| 方式(プロファイル) | 画質 | Pi4 負荷 | 容量 | 使う場面 |
|---|---|---|---|---|
| **Remux-MP4**(既定) | 原画質 | ほぼゼロ | 大 | 通常録画。宅内視聴・保存 |
| HW-H264-720p-2Mbps | そこそこ | 中(1本ずつ) | 小 | 宅外へ持ち出す番組だけ |
| SW-H264-720p | 高 | 大(遅い) | 小 | 画質優先で軽量化したい少数 |

> **Synology DS1825+ について**: この機種は AMD Ryzen で内蔵GPUが無く、ハードウェアトランスコード(QuickSync)は使えません。
> そのため変換は Pi4 側で行うのが前提です。DS1825+ は CPU が強力なので、将来 **Jellyfin/Emby/Plex** を入れて
> Remux 保存した原画質MP4を宅外視聴時に**オンデマンドでソフトウェア変換**する運用も実用的です(事前HWエンコを最小化できる)。

## 録画〜視聴の流れ

1. EPGStation で予約(手動 or キーワード自動)
2. 録画は外付けSSD(一時)へ → 完了後 NAS の最終保存先へ
3. エンコードが自動実行され、軽量 MP4 を生成
4. Synology **DS Video** / Android TV の **VLC** 等で NAS 上の MP4 を再生

## よくある調整

- **画質を上げたい**: [エンコード]で SW(x264)+ CRF を下げる(例 21)。Pi4 は処理が遅くなる点に注意。
- **容量を節約したい**: HW のまま解像度/ビットレートを下げる(例 480p / 1200k)。
- **録画が始まらない**: [ダッシュボード]でチューナー数・B-CAS 状態を確認 → [サービス]でログ確認。
- **NAS が見えない**: [保存先/NAS]で再接続。認証情報は再入力が必要です。
