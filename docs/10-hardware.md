# ハードウェア構成

## 必要なもの

| 種別 | 推奨 | 備考 |
|---|---|---|
| 本体 | Raspberry Pi 4 (4GB/8GB) | HW エンコード重視なら Pi4。画質重視なら Pi5+SW も可(考察参照) |
| チューナー | PLEX PX-Q1UD | 地デジ4ch。**付属ACアダプタで給電**(PiのUSBから給電しない) |
| カードリーダー | SCR3310 等 USB ICカードリーダー | pcscd で認識 |
| B-CAS | 1枚 | pcscd 経由で4チューナー共有 |
| 一時保存 | **USB3 外付け SSD** | microSD 直書きは非推奨(寿命/速度) |
| 最終保存 | NAS (Synology 等) | SMB で自動マウント |
| 冷却 | ヒートシンク＋ファン付きケース | 4ch録画＋エンコードは高発熱 |
| 電源 | 公式 USB-C 電源(5V/3A) | 電力不足はチューナー不安定の原因 |
| microSD | 16GB 以上(A1/A2) | OS 用。録画には使わない |

## 接続

```
Pi4 ─ USB3 ┬─ 外付けSSD (録画一時/エンコード作業)
           └─ USBハブ(セルフパワー) ┬─ PX-Q1UD (別途ACアダプタ)
                                     └─ ICカードリーダー + B-CAS
Pi4 ─ 有線LAN(推奨) ─ ルータ ─ NAS
```

- **有線LAN推奨**: 4ch録画＋NAS転送はWiFiだと不安定になりがち。WiFi 設定も管理パネルから可能。
- PX-Q1UD とカードリーダーは**セルフパワーUSBハブ**経由が安全(Pi の給電能力対策)。

## 動作確認(SSH で確認したい場合のみ・通常は不要)

```bash
# チューナー(DVBアダプタ)が4つ見えるか
ls /dev/dvb/            # adapter0 .. adapter3

# B-CAS が読めるか
pcsc_scan               # カード情報が表示されれば OK
```
